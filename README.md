# 🍽️ Con Amore — Управление бронированием столиков

**Con Amore** — это веб-приложение для управления бронированием столиков в итальянском ресторане. Проект предоставляет гостям удобный интерфейс для выбора и бронирования столиков, а администраторам — мощные инструменты для управления заведениями, бронями и контентом.

## ✨ Основные функции

### Для всех пользователей
- **Главная страница** с меню и формой поиска свободных столиков.
- **Поиск столиков** по дате, времени и количеству гостей.
- **Онлайн-бронирование** выбранного столика.
- **Просмотр фотографий** ресторана (доступно всем).
- **Добавление отзывов** (доступно без регистрации).
- **Страница с контактами** и информацией о ресторане.

### Для управляющих (персонала)
- **Управление столиками**: создание, редактирование, удаление и просмотр всех столиков.
- **Управление бронями**: изменение статуса, удаление и просмотр всех броней.
- **Управление контентом**: добавление фотографий ресторана (только для управляющих).
- **Регистрация и вход** через отдельную форму.

### Технические особенности
- **Кэширование** списков столиков и броней для повышения производительности.
- **Отложенная задача** напоминания о брони (письмо на email за 12 часов до визита).
- **Контейнеризация** с использованием Docker и Docker Compose.
- **Модульная архитектура**, готовая к масштабированию.

## 🚀 Установка и запуск

### 📁 Локальная установка (без Docker)

1. Клонируйте репозиторий:
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Con_Amore)
2. Создайте виртуальное окружение и активируйте его:
   (`python -m venv venv`)
   (`source venv/bin/activate`)
3. Установите зависимости:
   (`pip requirements.txt`)
5. Создайте файл .env в корне проекта на основе .env.example
6. Примените миграции:
   (`python manage.py migrate`)
8. Соберите статические файлы:
   (`python manage.py collectstatic --noinput`)
10. Запустите сервер:
   (`python manage.py runserver`)
11. Запустите Celery и Celery beat (в отдельных терминалах):
   (`celery -A config worker --loglevel=info -P eventlet`)
   (`celery -A config beat --scheduler django --loglevel=info`)
12. Откройте приложение в браузере:
     http://127.0.0.1:8000

### 🐳 Запуск через Docker (рекомендуемый)

1. Убедитесь, что Docker и Docker Compose установлены на вашей системе.
2. Клонируйте репозиторий и перейдите в папку проекта:
   (`git clone`) [GitHub](https://github.com/SuchkovaMaria/Con_Amore)
4. Создайте файл .env в корне проекта на основе .env.example.
5. Запустите проект одной командой:
   (`docker-compose up -d`)
6. Проверьте статус контейнеров:
   (`docker-compose ps`)
8.  Загрузите тестовые данные из фикстуры (при необходимости):
   (`docker-compose run --rm web python manage.py loaddata con_amore/fixtures/con_amore_data.json`)
9. Создайте суперпользователя:
   (`docker-compose run --rm web python manage.py csu`)
10. Остановите и удалите контейнеры (для завершения работы):
    (`docker-compose down`)

### 🧑‍💻 Использование
#### 🧑‍🤝‍🧑 Для гостей
1. Ознакомьтесь с меню в разделе главной страницы "Меню"
2. На главной странице выберите раздел "Зарезервировать столик" и укажите дату, время и количество гостей.
2. Нажмите «Показать доступные столики». 
3. Выберите подходящий столик из списка и нажмите «Забронировать». 
4. Заполните форму: имя, email, телефон. 
5. Получите напоминание за 12 часов о бронирования на email.

#### 🔑 Для управляющих
1. Нажмите «Войти» в верхнем меню, авторизуйтесь и ожидайте пока администратор включит в группу "Управляющие"
2. После входа станут доступны пункты:
- Управление столиками: создание, редактирование, удаление. 
- Управление бронями: просмотр, корректировка, удаление. 
- Управление фото: добавление фотографий в галерею.

#### Через административный интерфейс проекта:
- добавление в группу "Управляющие"
- Удаоение/редактирование фото и отзывов.
